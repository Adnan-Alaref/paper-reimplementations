# Paper Reimplementations

A collection of research paper reimplementations built from scratch.

The goal is to understand each paper from:

**Paper → Mathematics → Architecture → Implementation → Experiments**

---

## 📚 Papers

### 1. Attention Is All You Need (2017)

**Paper:** *Attention Is All You Need*  
**Authors:** Vaswani et al.  
**Year:** 2017

A from-scratch reimplementation of the Transformer architecture introduced in the paper.

#### Implementation

- Scaled Dot-Product Attention
- Multi-Head Attention
- Positional Encoding
- Feed-Forward Network
- Encoder
- Decoder
- Masking
- Transformer
- Training
- Evaluation

#### Application

**English → Arabic Neural Machine Translation**
